Trust this demo server

To run the muscle (EMG) game, this tablet needs to trust the demo server's certificate once. Two steps: download it, then turn trust on.

1 — Download the certificate

If nothing happens, your browser downloaded a file called rootCA.crt. Continue with the steps below.

2 — Install & trust (iOS/iPadOS)
  1. After downloading, tap Allow to download the profile.
  2. Open Settings → General → VPN & Device Management, tap the mkcert profile, then Install (enter passcode).
  3. Then go to Settings → General → About → Certificate Trust Settings and switch ON the mkcert certificate.

The second step (Certificate Trust Settings) is easy to miss — without it the game still won't get the mic.

2 — Install (Android)
  1. Open Settings and search for “CA certificate” (Security → Encryption & credentials → Install a certificate → CA certificate).
  2. Pick the downloaded rootCA.crt and confirm.
  3. You may need a screen lock (PIN/pattern) set on the device first.

Chrome may show a “network may be monitored” note — that's expected for a local demo certificate.

2 — Install (Windows)
  1. Open the downloaded rootCA.crt → Install Certificate.
  2. Choose Current User → Place all certificates in the following store → Trusted Root Certification Authorities → Finish, and accept the warning.
On a managed/work Windows tablet, IT policy may block installing a root certificate. If it fails, use an iPad or Android tablet for the EMG game, or ask whoever set up the kit to pre-install it.
