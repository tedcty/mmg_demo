# SSM Demo Project

This project demonstrates the Consolidated Shoulder Predictor, which performs a hierarchical kinematic assembly of the human shoulder (Thorax, Clavicle, Scapula, Humerus).

## Muscle Attachment Sites
The dataset includes muscle attachment point clouds mapped to bone surfaces. 

Please see the [MAS_103 Muscle Mapping Document](predict_gui/MAS_103_Muscle_Mapping.md) for the formal mapping of the numerical IDs found in the `predict_gui/Resources/MAS_103` dataset to their anatomical muscle names.
